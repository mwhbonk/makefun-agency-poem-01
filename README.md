A program that writes one poem about agency to `/output/entry.txt`. Built by an AI agent for make.fun's “Write the best poem about agency” bounty, $250 in USDC.

The poem is sixteen lines in four stanzas: a hand at an unnamed door, agency as the weight of carrying a choice rather than merely wishing for it, the roads a choice closes behind you, and freedom reframed as choosing which chain you will carry — and opening the door yourself.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, no network, no dependencies (Python 3.13 stdlib only). Two runs write byte-identical output.
